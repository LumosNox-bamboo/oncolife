# OncoLife V0.3 · 完整治疗历程与临床挑战

中文像素医院游戏，原项目就地升级。医生／患者两条线独立，保留 Phaser 地图、自由移动、自动寻路、快速旅行和本地存档。全部患者、费用、等待与剧情都是虚构教学内容；不是临床决策工具。

## 安装和启动

需要 Node.js 20.19+ 或 22+。

```sh
npm ci
npm run dev
# 浏览器打开 http://127.0.0.1:5188/
npm test
npm run build
npm run test:e2e
```

也可运行 `bash scripts/install.sh` 和 `bash scripts/start.sh`。macOS 推荐 `bash scripts/start-background.sh`：由当前登录会话托管，退出聊天后仍运行，异常退出会重启；不设置开机自启，退出登录或重启电脑后需再次执行。停止服务用 `bash scripts/stop-background.sh`，日志位于 `.runtime/`。后台服务占用 5188 时无需再运行前台启动脚本。E2E 默认使用 macOS Google Chrome；其他系统请调整 `playwright.config.ts` 的 executablePath，或安装 Playwright Chromium。无真实患者数据、在线模型或云存档。

## 操作

- 主菜单先选择医生／患者，再选择病例和模式。每种组合自动保存，再次选择相同组合继续。
- WASD／方向键移动，E 或点击近处对象互动，Esc 关闭。手机方向按钮支持移动。
- 地图下方快速旅行／自动寻路；当前任务地点会带到对应房间。面板内可以切换病历、报告、治疗、病房与日程，减少重复跑图。
- “下一事件”、＋1 天、＋1 周统一停在最早未处理事件。已生成报告必须查看确认，日期不会越过它。
- 日程显示计划、可用、发生、查看、完成时间。未知剧情到发生时才显示。
- 在治疗日点击安全复核，NPC 完成当日血液与肾功能复查及其他核对（120 游戏币，教学即时报告）。然后执行治疗；不是点首剂就结束。
- 存档自动写入，也可手动保存／导出 JSON。医生与患者、不同模式和病例互不覆盖。旧 V0.1/V0.2 存档原样保留、可导出，**没有自动迁移成 V0.3 的新周期结构**。

## 一条可完成的医生路线（含答案）

选择学习模式、林晓禾病例。

1. 门诊问诊并讨论患者目标。申请 CT、胸膜取样；推进时间，在检查面板查看确认报告。
2. 有组织后申请病理；查看后申请分子检测。申请并查看基线血常规与肾功能。
3. 门诊提交“肺腺癌／IVA 教学情境”，填写影像、胸膜组织和分子依据。错误可以修订，不会判定患者死亡。
4. 治疗室建立方案，或共同选择先支持照护并约定复评。本病例暂不接受免疫治疗的背景下演示培美曲塞＋铂类路径，不是所有患者的默认选择。
5. 下一事件到治疗日：完成安全复核→执行治疗。每个周期都需要重新复核。治疗可暂缓／恢复，后续预约整体平移；毒性后可记录调整决定，具体减量不由游戏生成。
6. 第一周期的固定发热事件：病房紧急评估→感染与血液检查→启动急诊处置与支持。不能仅等待或点“确认”跳过。
7. 查看恢复及周期监测，完成周期评估。继续全部四个 21 天周期；之后还要完成疗程后随访才到阶段终点。
8. 更换或终止原计划也会生成后续 MDT／症状复评，不立即胜利。

## 患者路线

症状期可再观察两天或立即就医，描述症状并联系家属。医生 NPC 根据证据安排 CT→适用取材→病理→需要时的分子检测；每次“了解并同意下一项检查／治疗”只推进符合前置条件的步骤。报告逐步解锁，患者不提交诊断。可以表达暂缓意愿或选择先支持照护。

建立计划后，同意治疗前检查，参加当日评估、治疗、监测及周期复诊。发生异常时主动求助，医护 NPC 按既定规则处置。安排休息、交通和家庭支持会改变疲劳／经济压力等叙事值，不改变虚构生存概率。完成后获得患者视角的阶段总结。

## 三种模式

- **学习**：预算不限（内部用有限记账值以支持 JSON），提示和来源卡可查看。未执行订单可取消，错误可修订，支持重新练习。
- **闯关**：初步检查→组织与分期→分子和决策→治疗准备→毒性及周期→随访综合决策，六个目标顺序解锁。安全、推理、适当性、资源、时间、沟通分别记分。评分是教学规则，未经教育测量验证。
- **挑战**：初始 5000 游戏币、全院 1 个床位、每日 1 个加急影像及治疗资源。地图下方“当前患者”可接诊其他病例，所有在管患者共享预算、临床时间和资源。后台报告也会暂停时间，必须切换患者处理。急救不被加急影像名额阻挡。援助为每病例一次，非紧急项目可以协调转诊。

挑战还有种子 2026 的可复现交通事件：家属陪诊较贵但降低疲劳，公共交通较便宜但增加疲劳。种子只用于虚构生活安排，**不生成真实医学风险、疗效或生存概率**。

## 订单与财务

订单记录开立、预约、采样、处理、完成及失败。未执行取消退 80%；样本不足保留原已执行费用，重新取样另收 100；实验室技术失败可免费重做或全额退款，退款后不能免费重做。账本收费幂等、退款关联原收费且封顶。订单失败状态保留，财务状态由账本独立展示。以上均为游戏规则，不是医院／医保政策。

## 架构与扩展

- `src/world`：地图、碰撞、角色与路径。
- `src/engine/v03-types.ts`：领域类型；`v03-clock.ts`：统一时钟与调度；`v03-ledger.ts`：账本。
- `v03-engine.ts`：订单、住院、治疗、患者 NPC、事件与闯关状态转换。
- `v03-campaign.ts`：多患者共享资源；`v03-store.ts`：存档与 UI 状态。
- `src/medical/cases.ts`：病例与结构化日程；`knowledge.ts`／`investigations.ts`：保留来源和检查知识；`validate.ts`：基本一致性校验。
- `src/ui/V03Panel.tsx`：弹出式交互；医学规则不写在 UI 中。

新增病例：扩充 CaseId 和 cases，明确初始线索、候选检查、病理／分期／分子、意愿、方案和终点；新增特殊事件时添加有类型的命令与状态转换，再加入完整流程测试。新增知识：在 knowledge.sources 添加版本、来源 URL、适用地区和核验边界，再引用来源 ID；未验证处方必须保留 teachingPlaceholder，不能当临床推荐。

## 测试与限制

详见 `docs/V03_TEST_RESULTS.md`、`docs/V03_DEVELOPMENT_LOG.md`、`docs/MEDICAL_SOURCES.md` 和 `docs/V03_LIMITATIONS.md`。旧版源码／逻辑测试与文档保留，旧浏览器脚本在 tests/archive。

当前主要限制：非默认方案是简化管理教学路径；未做独立临床专家审查；剂量调整是带门槛的决策记录而非药代／疗效模型；重新制定方案止于 MDT 阶段终点，尚不支持任意二线处方；病理＋免疫组化作为同一订单；真实医保、持续住院每日收费、复杂病床排队与移动端多指操作未完整模拟。正式医疗推荐和真实患者数据均不在范围内。

## 病例资料恢复修订（2026-10-28）

在门诊打开「病历」可查看生命体征，完成相应问诊后显示具体病史、暴露史、体格检查与患者目标。「检查与报告」显示实际申请的分项结果；「日程与账单」中的「检查档案」按日期保留已查看报告。尚未申请或查看的结果不会提前显示。

林晓禾恢复原版具体教学记录，包括血压 128/78 mmHg、20 包年吸烟史、3.6 cm 肺病灶、分子结果和血液数值。其他五例补充不同的影像尺寸、组织描述及生命体征，并明确标注为新编写的虚构病例数据。项目没有接入真实患者资料；未知药名、过敏史仍标记待核对。

现有 V0.3 存档无需重开：历史通用报告在显示时补充病例细节，保留原存档摘要、日期、费用与进度，不重新收费或采样。V0.1／V0.2 保留档仍不自动迁移。

详细病例资料位于 `src/medical/profiles.ts`；新增病例时须同时提供 profile 和分项报告，并补充结果逐步解锁测试。恢复记录见 `docs/V03_DEVELOPMENT_LOG.md`，测试截图为 `docs/v03-case-record-restored.png`。

## 多患者门诊（2026-10-30）

医生学习／闯关模式可点击地图下方「开启多患者接诊」，保留当前病例进度并进入共享时间的接诊队列。「接诊下一位」或「当前患者」下拉框可接入其余病例，最多六位，可每天接诊一位，也可同日接诊；没有强制每日配额或自动生成无限患者。未开启时仍保留原来的独立病例玩法。挑战模式继续默认共享有限资源。

检查等待期间可以处理其他患者；任何在管患者的到期报告／重要事件仍会阻止跳过，提示姓名后切换处理。多患者存档按主线和模式隔离；接入已有独立存档对应的新病例时，原独立记录备份到原键加 `-before-campaign`，不会把不同临床日期直接混在一起。

门诊问诊、检查和日间治疗不占住院床位；需住院观察或支持时在病房申请、入院、评估和出院。患者列表及状态栏显示门诊检查候报、治疗日、住院观察等；学习模式的多床位有独立编号。入院评估不赋予给药许可，各周期仍须治疗日安全复核。本版检验数值仅模拟血液与肾功能，尚未实现肝功能、电解质等完整化疗前检查，不能作为真实临床清单。

## 病例池扩展与随机接诊（2026-10-30）

病例池已扩展为 10 个虚构教学病例：早期腺癌、早期鳞癌、局部晚期、EGFR 驱动阳性、ALK 融合阳性、无明确靶点、少数转移灶、高龄合并症、小细胞肺癌、治疗后复发／进展。每例拥有不同的人口学资料、症状、合并症、影像线索、病理／分子结果、治疗目标和检查路径。

医生模式开启多患者接诊后，「接诊下一位」会从尚未接诊的病例中按存档种子抽取；随机结果可复现，刷新或重新载入不会换人。手动下拉列表仍可切换已接诊患者。每个病例资料均为虚构教学数据，不能当作真实患者数据或临床推荐。
