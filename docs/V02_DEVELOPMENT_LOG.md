# V0.2 开发记录 · 2026-10-26

在现有仓库直接重构，无新建无关项目，无改动其他游戏。

## 1 审计与基线

读取全部应用源码、现有测试、配置、启动脚本和 V0.1 说明；原版 12 单元测试与 2 浏览器测试通过。实际浏览器展开初诊知识卡发现明确诊断剧透，完整旧流程记录重复身份切换与跑图。审计见 V02_AUDIT.md。保留旧版 README、测试源和本轮基线结果。

## 2 领域模型

新增 journey.ts / persistence.ts；重写 store.ts。两条主线固定身份、各自任务／存档／结局；旧 v1 键不读入新临床进度、不覆盖。旧 clinical.ts 与 model.ts 保留供原回归测试，V0.2 不继续使用其强制换角流程。

诊断假设与报告分离，检查单创建时不保存结果字符串，只有到期才解析病例结果。证据快照保留当时已知信息。标本不足可以补样后重新做病理；未重新确认可用病理前不能做分子检测。错误猜测可修订，不捏造疾病惩罚。

## 3 双线故事与选择

医生自由问诊、影像／取样／病理／分子／分期，诊断提交后进行共同决策。首剂、当日安全核对与护理由 NPC 协作。患者从症状与就医开始，家庭支持或隐私、简述或补充、目标或负担提问、休息或陪诊、直接或家属陪同求助，形成独立高潮与日记。

两线都可选择先支持照护并约定复评或进入化疗准备；这不表示临床疗效等同。首诊可以不同顺序，取材不足路径增加真实记录的等待与游戏费用。会诊有额外成本，不改变编造的疗效。

## 4 地图与交互

原绘图和碰撞保留，map.ts 增加 BFS 与安全目标点，Hospital.ts 加入快速旅行及自动行走。main.tsx 双入口，JourneyPanel.tsx 独立视角面板。集中开单／报告减少行政跑图，保留实体科室功能、手动移动与 E。方向键取消自动路线，面板和菜单暂停移动。

## 5 核验与修复

- 原型候选卡“局限性”仍泄露本例胸膜转移与取材不足：浏览器无剧透断言发现，改为通用信息，结果仅到期揭示。
- UI 按钮附带说明改变可访问名称，测试最初 exact 定位失败：改为对应中文动作匹配，不放宽临床断言。
- 首次重构浏览器测试医生、患者与另一条路径通过，但立即缩小 viewport 时 Phaser 画布尚未重排：添加最大尺寸约束，并等待响应式布局收敛后断言宽度。
- 查出第二意见推进日期未触发待出报告：改为调用统一时间引擎逐日更新。
- 查出已提交诊断随后错误重提交可能保留已确认标记：重新提交先撤销确认，证据和判断再次通过才确认。进入治疗后阻止直接篡改已确认诊断。
- 查出补样后可能绕过重做不足病理直接分子检测：要求当前病理为可用结果。
- 临床规则引擎、表述与 UI 只针对本轮目标修改；未更换美术风格、依赖框架或加入云端系统。

## 6 验证与交付

具体命令、最终计数、浏览器路线、截图、限制及 Git 提交在 V02_TEST_RESULTS.md 与本文件末尾记录。源医学文件保留，新增 NICE 来源单独哈希。README 更新独立存档与完整操作方法。

## 剩余问题

- 仅一个虚构病例、确定性 NPC 与预写结果；不是通用临床推理系统。
- 暂不实现真实概率、处方剂量、后续周期、医保、多患者及其他职业主线。
- V0.1 旧档可读／下载，但不迁移为 V0.2 进度；要继续原流程需恢复旧版本。
- 仅 Chrome 桌面与模拟窄屏验收，尚无真实手机硬件与 Safari／Firefox 全流程。
- Phaser 主包仍有大于 500 KB 提示；本轮优先可玩性与流程，未扩大到构建优化。
- 没有临床专家独立审核。教学指标和固定剧情不可外推真实结局。
