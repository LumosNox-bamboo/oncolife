# OncoLife V0.1 开发日志

日期：2026-10-25。项目为独立目录与独立 Git 仓库，未修改相邻 Another Today 或其他现有作品。实现按依赖顺序推进；提交在验收收尾按七轮模块整理，不能把中间提交误认为每一轮均已独立可运行。最终 R7 及之后为完整交付。

## 第一轮：初始化

- 完成：独立 Git、React/TypeScript/Vite、Phaser、Zustand、Vitest、Playwright 依赖与锁文件。
- 决策：固定一个本地病例，localStorage，离线核心玩法；不接真实数据、不调用模型。
- 失败／修复：沙箱网络 DNS 受限，使用工具批准的联网安装与公开来源下载。
- 当轮未完成：地图、病例、UI 和验收。
- 提交：`R1: initialize isolated OncoLife project`。

## 第二轮：地图与控制

- 完成：连续医院地图、6 间临床房间＋大厅、家具、原创像素角色、行走动画、碰撞、近距离鼠标与键盘交互、触屏方向控制。
- 决策：单场景房间区域切换，保留清晰门口；简单 AABB 碰撞，步长限幅避免跨墙。
- 失败／修复：快速 E 漏帧在第七轮发现并修复为事件响应；自动路线绕过接待台。
- 当轮未完成：角色状态与临床面板接线。
- 提交：`R2: add walkable pixel hospital and interactions`。

## 第三轮：角色、患者与任务

- 完成：医生／护士／患者共用状态、主线任务、存读档、模式和预算基础。
- 决策：权限在引擎二次校验，不依靠隐藏 UI；刷新后位置回大厅而病例不变。
- 失败／修复：无独立角色存档分叉；重置病例需显式确认。
- 当轮未完成：诊疗事件与医学门槛接线。
- 提交：`R3: add shared roles tasks and persistence`。

## 第四轮：病例与知识库

- 完成：58 岁虚构转移性肺腺癌病例、资料来源、7 张知识卡、标签安全阈值。
- 决策：患者讨论后暂拒免疫，采用标签支持的培美曲塞＋顺铂周期，避免把三周化疗概括为全部肺癌。
- 失败／修复：CTCAE 旧 PDF 跳转 HTML，改用官方工作簿；核实 NCI 分期表及页面更新日期。
- 当轮未完成：真实概率模型（本版明确不做）、独立临床专家审核。
- 提交：`R4: add fictional case and verified medical provenance`。

## 第五轮：诊疗与时间引擎

- 完成：检查延迟、报告、路径讨论、患者意愿与会诊前置条件、准备／审核／执行、固定发热剧情、多步骤处置、恢复／随访／结局、虚构费用、日志。
- 决策：医学规则与 UI 分离；固定事件不冒充概率；严重毒性后不自动执行第二周期；NICE 仅支持紧急处理原则，不给处方。
- 失败／修复：重审核须可重复而给药不得重复；新增过期重审核回归测试。
- 当轮未完成：第二周期减量执行、多患者调度。
- 提交：`R5: implement clinical time treatment and safety events`。

## 第六轮：UI、美术与声音

- 完成：地图为中心的 HUD、中文科室交互、病例／报告／时间线、模式重置确认、知识解锁、结局、环境音开关、响应式布局。
- 决策：面板按需出现，不采用常驻网页仪表盘；原生字体与原创合成声音。
- 失败／修复：移除空 CSS import；窄屏采用方向按钮，保留横屏建议。
- 当轮未完成：模拟摇杆、复杂景深／天气、挑战模式。
- 提交：`R6: connect Chinese game interface and ambient audio`。

## 第七轮：测试修复与交付

- 完成：12 项逻辑测试、2 项浏览器测试、完整键盘病例、刷新续档、移动端布局、README、启动脚本、医学来源与校验值、验收报告。
- 决策：浏览器测试只读坐标用于等待，业务操作走真实 UI；不以引擎测试替代实际试玩。
- 失败／修复：详见 TEST_RESULTS.md 的 6 条记录。测试期间的热更新冲突未算通过；冻结源码后的完整流程通过。
- 保留限制：概率模型、挑战模式、后续周期、通用多病例、完整经济系统未实现；移动端为基础适配。生产包仍有尺寸提示。
- 提交：`R7: verify playable case and document V0.1 delivery`。
