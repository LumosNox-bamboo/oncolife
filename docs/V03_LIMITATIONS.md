# V0.3 实现范围与剩余问题

## 已实现
- 双主线、原医院地图与七个交互入口、碰撞、快速旅行、寻路、触控。
- 最早待处理事件截停所有时间推进；报告当天生成与确认分离；同日确定性优先级。
- 检查取消、样本不足重取样、实验室失败免费重做／退款，独立幂等交易账本。
- 申请、入院、床位占用、入院评估、观察、出院与复查预约。
- 默认病例四周期、每次安全复核、监测、急性事件评估处置、周期评估及疗程后随访。
- 六病例可达阶段终点；六关依次解锁；挑战多患者共享时间、资金、床位与每日资源。
- 存档隔离、导出、旧键保留；来源显示；确定性医疗剧情和可复现生活事件分离。

## 部分实现
- 六病例的路径、数据和日程确实不同，但手术、局部治疗、靶向、小细胞、复发仍是明确标记的管理教学节点，不是完整循证治疗协议。
- 剂量调整需已有毒性评估，实际剂量不输出；换方案停止原预约并进入 MDT 复评，未执行任意新处方。
- 当日血液复查由 NPC 即时生成固定教学报告，真实等待、恢复速度和检验变异未模拟。
- 闯关六维评分可变化，但不是经过验证的评价量表，没有复杂加权与金标准评分。
- 住院观察是状态与记录，不包含每日床费、细致护理操作和动态床位队列。
- 订单状态包含扩展类型；采样和处理可在一次时间推进内发生，技术失败与样本不足以不同原因处理，未单独模拟每个实验室工作站。
- 患者线具有独立决定、NPC 流程与结局文案，治疗日程仍共享临床引擎。

## 未实现／后续建议
- 真实剂量与药物组合、真实疾病自然史／疗效概率、独立临床专家签审。
- V0.2 进行中存档向新周期结构自动迁移；仅保留旧键并支持下载，不静默覆盖。
- 云同步、公开部署、多设备共同存档、音效及触控在所有移动设备上的全面验证。
- 优先后续：临床专家审核六病例证据链，再扩展经验证方案和各病例专属事件；完善处方切换、安全参数与保存文件导入。
