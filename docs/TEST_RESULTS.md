- 完整流程通过真实方向键及 E 键进入房间、点击业务按钮；测试仅只读场景坐标用于等待，没有直接传送、写病例状态或绕过临床引擎。
- 完整流程捕获的 `pageerror` 列表为空。刷新后 localStorage 病例与刷新前完全一致。
- 已查看桌面地图、手机地图与结局页面截图，当前画面无明显遮挡主线操作的问题。长病历面板内部可滚动。

## 失败与修复记录

1. 默认沙箱不能绑定本地端口；经权限工具允许的本地服务器运行测试，未修改或停止其他项目服务。
2. 首版测试的异步位置条件未等待实际移动；改成明确等待坐标到达的轮询断言。
3. 真实游戏快速按 E 可能落在两帧之间；改为键盘 keydown 事件触发交互，修复后完整 E 键流程通过。
4. 自动路线曾撞上大厅接待台；修正测试路线绕行，未关闭家具碰撞。
5. 一轮测试与源码编辑重叠，Vite 热更新使只读场景引用失效；此轮记为失败，不算验收。冻结源码后重新执行完整测试通过。
6. 首版空 CSS import 构建提示已删除。旧 CTCAE PDF URL 实际返回 HTML，保留原响应，改用官方 v5 工作簿核验。

## 测试边界

未做真实手机硬件、Safari／Firefox、长时间运行、多病例、多人协作、药物真实处方验证或临床专家独立审核。浏览器闭环只覆盖学习模式；临床预算闭环由独立逻辑测试验证。生产构建已通过，完整交互浏览器测试使用 Vite 开发服务器。
