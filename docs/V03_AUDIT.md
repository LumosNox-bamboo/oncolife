# V0.3 审计（2026-10-27）

基线：V0.2 提交 837519e；接手时已有未接入的 V0.3 草稿。此前 localhost:5188 没有服务运行，已恢复 Vite。

发现并修复：
- 地图切换到 V0.3 store，但主界面仍读 V0.2，且引用不存在的 role，导致构建失败。
- 到期检查直接变成 completed，但没有结果；下一事件只检索 requiresAction 导致遗漏。
- 退款缺乏引擎/UI 完整入口、旧订单可重复扣费；退款关联改为原收费交易 ID。
- 给药没有未来事件，首剂后无完整日程；现在按结构化周期建立给药、监测、周期评估和疗程后随访。
- 初稿手动 complete 和 stop 可直接胜利；删除直接完成命令，终止治疗也必须完成随访。
- 初诊下拉框只提供当前正确诊断、病例标题剧透；改为通用候选，游戏 HUD 仅显示姓名。
- 初稿患者线不能提交诊断且没有 NPC 行为；补充证据驱动的就医、同意检查、沟通与治疗路径。
- 学习预算 Infinity 经 JSON 保存成为 null；改为有限内部记账值，界面按模式显示不限。
- 请求住院后直接出院会释放不存在的床位；改为申请→入院→评估观察→出院。
- 原始非默认方案均未验证具体处方，不冒充真实治疗推荐；小细胞病例不再复用同步放化疗名称。

体验策略：保留医院像素地图与移动；房间内面板可直接切换相关任务，常驻界面保持小型 HUD。只在实际发生时显示急性剧情，未来仅展示已知预约。

验收原则：旧逻辑回归继续运行，新增 V0.3 状态测试与真实浏览器点击流程。菜单或占位方案不计为完整临床方案。
