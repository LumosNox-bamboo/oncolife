## 十项验收映射

| 要求 | 已执行验证 |
|---|---|
| 1 医生独立完成 | 自由问诊、CT、血液／组织／病理／分子／分期、错误假设修订、共同决定、准备／首剂、紧急评估、首次复诊 |
| 2 患者独立完成 | 就医与家庭沟通、完整描述、检查／等待、NPC 解释、主动提问、治疗体验、求助高潮、生活安排与日记结局 |
| 3 无强制换角 | 两线最终 role 均为初始主线；UI 无护士身份切换入口；医嘱由 NPC 协同执行 |
| 4 自主选检 | UI 自选 CT／X 线、检查申请；逻辑覆盖不同顺序、标本不足、补样与重复申请防护 |
| 5 按实际申请解锁 | 未申请没有结果；等待单不含 result；第一批报告后显示对应线索，未做病理／分子不泄露结果 |
| 6 多路径 | 医生直接 CT／先 X 线；不同血液／分期／取材顺序；不足标本补样；支持照护与化疗；临床／影像复诊；患者陪伴与独立路径 |
| 7 初诊不暴露答案 | 新状态无肺腺癌／IVA／分子结论；UI 无已确诊胸膜转移或 PD-L1 数值；候选诊断是空白工作台选项，不是预填答案 |
| 8 快速旅行与时间 | 每次 UI 临床交互使用快速旅行＋E；真实自动寻路进入门诊，真实按键撞墙；任务直达；结果／事件自动暂停 |
| 9 独立存档 | 医生和患者双槽位交替、刷新、回读一致；旧 v1 fixture 原样保留；重开只操作当前槽位 |
| 10 核心回归 | 原地图、家具碰撞、所有房间连通、手动移动、触屏布局、检查、临床安全门槛、时间暂停、日志、存档及既有来源保留 |

## 5 条实际浏览器路线

1. 医生化疗线：包括错误分期 III 后修订 IVA、首剂后异常、紧急处置、临床复诊、刷新。约 3.4 秒自动点击执行。
2. 患者化疗线：家属支持、共同决定、陪诊、异常求助、日记；进入医生线不继承患者进度。约 2.5 秒。
3. 医生替代路径：X 线 → CT、第二意见、支持照护、影像复诊。约 2.1 秒。
4. 原生像素操作：自动寻路、E、按住方向键撞墙、任务直达、390×844 布局无横向溢出。约 6.9 秒。
5. 患者替代路径：先安排家事增加 2 天、独自整理、两槽位中途保存刷新、支持照护、独立休息、日记；旧 v1 day=42 未被改写。约 2.4 秒。

“3 分钟首批线索”由浏览器计时断言覆盖，从进入医生线、问诊、选 CT 到得到首批结果 <180 秒。自动化点击速度并不等于真实玩家阅读速度，未进行用户研究。

## 独立逻辑回归重点

涵盖权限、标本依赖、诊断证据、不足病理阻断分子、无结果提前泄露、错误重提交撤销确认、历史证据不回填未来报告、预算不足、准备时间、重复给药、紧急事件不能靠等待跳过、第二意见同步更新时间、周期第 15 天监测、四类双线结局、存档隔离／损坏回退、寻路不穿墙。
